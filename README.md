# ✦ Campus Queue Management System

<p align="center">
  <i>A simple C++ console-based application for managing campus service queues.</i>
</p>

## ✧ Features

- 🎫 **Take Queue** — Generate automatic queue numbers.
- 📋 **View Queue** — Display registered customers.
- 🔐 **Staff Login** — Access the staff menu.
- 📢 **Call Next** — Serve customers using FIFO principles.
- 📊 **Queue Status** — Monitor current and remaining queues.

## 🛠️ Built With

- C++
- Struct & Functions
- Pointers & Dynamic Arrays
- Dynamic Memory Allocation
- FIFO (First In, First Out)
